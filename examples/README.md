# Gleeful Transformer examples

From the repository root, install with `python -m pip install -e .`. Run each script from its example directory so its data and model paths resolve there.

| Workflow | Example |
| --- | --- |
| Pretrain a causal language model on packed text | [Common Corpus](pretraining/chat/common_corpus/) |
| Fine-tune a chat model on instruction and response pairs | [Databricks Dolly](fine_tuning/chat/databricks/) |
| Build, query, and optionally publish a vector index | [Gleeful Search Hello World](search/hello_world/) |

Run any script with `--help` to see its arguments.
